# Focus HQ — Персональный центр продуктивности

**Focus HQ** — это персональное веб-приложение для ежедневного управления задачами, целями, воронкой клиентов студии **WebCraft Studio**, привычками, помодоро-сессиями и вечерней рефлексией.

Интерфейс приложения полностью на **русском языке**.

---

## ⚡️ Технологический стек

- **React 19** + **Vite 6** + **TypeScript**
- **Tailwind CSS v4** с кастомной темой, темным оформлением по умолчанию и поддержкой светлой темы
- **Lucide React** — современные иконки
- **Recharts** — интерактивные графики аналитики продуктивности и выручки
- **Canvas Confetti** — приятные анимации при закрытии сделок и выполнении задач
- **Web Audio API** — мягкий колокольчик / chime при завершении помодоро-сессий (работает автономно без внешних аудио-файлов)
- **Web Notifications API** — системные браузерные push-уведомления
- **PWA (Progressive Web App)** — манифест `manifest.json`, сервисный воркер `sw.js` и иконки для установки на домашний экран смартфона (iOS/Android)
- **Zero Backend / 100% Offline** — все данные надежно сохраняются в `localStorage` через изолированный слой хранения с обработкой ошибок `try/catch`. Поддерживается мгновенный экспорт и импорт в JSON.

## 🌟 Основные модули и функционал

### 1. Дашборд (Главная страница)
- **Приветствие по времени суток** («Доброе утро», «Добрый день», «Добрый вечер», «Доброй ночи») и сегодняшняя дата на русском языке.
- **Список задач на сегодня** с инлайн-полем быстрого добавления (нажмите `Enter`, чтобы создать задачу с датой «сегодня»).
- **Круговой индикатор прогресса (Progress Ring)** — наглядный процент выполнения намеченных на сегодня задач.
- **Текущая серия продуктивности (Streak)** — подсчет дней подряд с хотя бы одной выполненной задачей с огоньком.
- **Топ-3 активные цели** с прогресс-барами и дедлайнами.
- **Виджет трекера дохода** — фактический заработок за текущий месяц против целевого ориентира (по умолчанию $1,000, редактируется в настройках).
- **Быстрый счетчик аутрича** — кнопка «+1 отправлено» для фиксации отправок прямо с главной страницы.

### 2. Задачи (Tasks)
- **Поля задачи:** название, описание/заметки, приоритет (Высокий / Средний / Низкий), дедлайн, тег/категория, статус (К выполнению / В процессе / Выполнено), регулярность (Без повтора / Ежедневно / Еженедельно), привязка к цели.
- **Два режима отображения:** 
  - **Список** с возможностью раскрытия чек-листа подзадач.
  - **Канбан-доска** с Drag-and-Drop перетаскиванием между колонками и кнопками быстрого перемещения на мобильных устройствах.
- **Фильтрация и сортировка:** фильтры по приоритету, тегу, сроку (сегодня, предстоящие, просроченные), полнотекстовый поиск (`/`) и сортировка по дате, приоритету или названию.
- **Чек-лист подзадач** с отслеживанием прогресса (например, 2/3).

### 3. Стратегические цели (Goals)
- Поля: название, описание стратегии, дедлайн, измеримая цель (число + единица измерения, например: `$2500`, `10 клиентов`, `%`).
- **Два режима расчета прогресса:** автоматический подсчет на основе выполнения привязанных задач или ручной ввод/ползунок текущего значения.
- **Контрольные точки (Milestones)** внутри каждой цели.
- Статусы: Активна / Завершена / На паузе.

### 4. CRM WebCraft Studio
- **Воронка лидов (5 этапов):** Связались → Ответил → Переговоры / КП → Сделка (Выиграно 🎉) → Отказ.
- Карточки лидов с суммой чека сделки, ссылкой на контакт (Telegram, WhatsApp, сайт), нишей и заметками.
- **Два режима:** интерактивный Канбан-пайплайн с подсчетом суммы сделок на каждом этапе и сводная таблица.
- **Метрики CRM:** отправлено сегодня, конверсия в ответ (Reply Rate), конверсия в сделку (Win Rate), общий заработок студии.
- **Дневной план аутрича:** целевой показатель (по умолчанию 15 писем/сообщений в день) с кнопкой «+1 отправлено».
- **Шаблоны сообщений (Scripts):** готовые продающие скрипты для холодного поиска и фоллоу-апов с копированием в буфер обмена в 1 клик.

### 5. Привычки & Вечерний обзор (Habits & Daily Review)
- **Недельная матрица привычек:** 7-дневная сетка (Пн–Вс) с цветовой маркировкой и отметкой в один клик.
- **Форма вечернего обзора:**
  1. *Что получилось сделать за день?*
  2. *Что пошло не так / какие были трудности?*
  3. *План на завтра (Топ-3 задачи)*
  4. Оценка продуктивности дня (1–5 звезд).
- **История обзоров:** хронологический архив предыдущих дней с оценками и инсайтами.

### 6. Помодоро таймер (Pomodoro)
- Спринты: Фокус (25 мин), Короткий перерыв (5 мин), Длинный перерыв (15 мин) с возможностью тонкой настройки длительности.
- Привязка таймера к конкретной задаче из списка.
- Подсчет чистого времени фокуса за день.
- Звуковой сигнал завершения (Web Audio API) и системное браузерное push-уведомление (с запросом разрешений).
- Управление: Старт, Пауза, Сброс, Пропуск сессии.

### 7. Аналитика (Statistics)
- **Графики Recharts:**
  - Динамика выполненных задач по дням недели (Bar Chart).
  - Чистое время глубокого фокуса в минутах (Area Chart).
  - Факт отправок аутрича против ежедневного плана (Line Chart).
  - Ежемесячный рост выручки веб-студии в $ (Bar Chart).

### 8. Резервное копирование и безопасность данных
- **Экспорт в JSON:** скачивание файла `.json` на компьютер/телефон в 1 клик или копирование содержимого в буфер обмена.
- **Импорт из JSON:** восстановление всех задач, целей, клиентов CRM и истории из сохраненного файла.
- Кнопка сброса до реалистичных демонстрационных данных.
- Кнопка полной очистки данных.

## 🚀 Локальный запуск разработки

Требования: установленный **Node.js 18+** и **npm**.

```bash
# 1. Клонировать репозиторий или перейти в папку проекта
cd sndnt

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется по адресу `http://localhost:5173/`.

Собрать оптимизированный production-бандл:
```bash
npm run build
```

Проверить production-сборку локально:
```bash
npm run preview
```

## 🌐 Развертывание (Деплой)

Приложение является полностью статическим (Single Page Application) с относительными путями (`base: './'`), поэтому оно работает на любом бесплатном хостинге без настройки бэкенда.

### Вариант 1: Деплой на GitHub Pages

#### Способ А: Через пакет `gh-pages`
1. Установите `gh-pages`:
   ```bash
   npm install -D gh-pages
   ```
2. Добавьте в `package.json` скрипт:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
3. Выполните:
   ```bash
   npm run deploy
   ```

#### Способ Б: Через GitHub Actions (рекомендуется)
1. Создайте в репозитории файл `.github/workflows/deploy.yml`:
   ```yaml
   name: Deploy to GitHub Pages

   on:
     push:
       branches: [main]

   permissions:
     contents: read
     pages: write
     id-token: write

   concurrency:
     group: 'pages'
     cancel-in-progress: true

   jobs:
     deploy:
       environment:
         name: github-pages
         url: ${{ steps.deployment.outputs.page_url }}
       runs-on: ubuntu-latest
       steps:
         - name: Checkout
           uses: actions/checkout@v4
         - name: Setup Node
           uses: actions/setup-node@v4
           with:
             node-version: 20
         - name: Install dependencies
           run: npm ci
         - name: Build
           run: npm run build
         - name: Setup Pages
           uses: actions/configure-pages@v4
         - name: Upload artifact
           uses: actions/upload-pages-artifact@v3
           with:
             path: './dist'
         - name: Deploy to GitHub Pages
           id: deployment
           uses: actions/deploy-pages@v4
   ```
2. В настройках репозитория на GitHub перейдите в **Settings → Pages** и в качестве источника выберите **GitHub Actions**.

---

### Вариант 2: Деплой на Netlify

#### Способ А: Drag & Drop (за 30 секунд)
1. Запустите локально сборку:
   ```bash
   npm run build
   ```
2. Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащите папку `dist` мышкой в окно браузера — сайт будет мгновенно опубликован и получит бесплатный SSL-сертификат.

#### Способ Б: Подключение через GitHub
1. Нажмите **Add new site → Import an existing project** на Netlify.
2. Выберите ваш GitHub репозиторий.
3. Настройки сборки установятся автоматически:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Нажмите **Deploy Focus HQ**.

## 📱 Установка как PWA на смартфон

1. Откройте опубликованный сайт в мобильном браузере:
   - На **iOS (Safari):** нажмите кнопку «Поделиться» (иконка со стрелочкой вверх) → выберите **«На экран "Домой"»**.
   - На **Android (Chrome):** нажмите меню (три точки) → выберите **«Установить приложение»** или **«Добавить на главный экран»**.
2. Приложение появится среди ваших мобильных приложений с собственной иконкой, запускается без интерфейса браузера на полный экран и работает автономно даже при отсутствии интернета.
